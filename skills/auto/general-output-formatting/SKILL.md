---
name: general-output-formatting
description: Use when generating output files to ensure compliance with specified formats.
---
1. Review the required output format specifications before generating any files.
2. Ensure that all required keys are present in the output.
3. Validate the data types and formats for each key (e.g., integers for counts, strings for names).
4. Check for any specific formatting rules (e.g., currency in cents, date formats).
5. Ensure that the output is structured correctly (e.g., JSON objects, CSV headers).
6. If applicable, sort the output data as specified (e.g., by timestamp or service).
7. Include any necessary metadata in the output (e.g., source file name, row counts).
8. Perform a self-check to confirm that the output matches the expected format and content.
9. If using a library for output, consult its documentation for best practices.

**Self-check:**
- Does the output file contain all required keys?
- Are the values formatted correctly according to the specifications?
- Is the output structured as required (e.g., JSON, CSV)?
