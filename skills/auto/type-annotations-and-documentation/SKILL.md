---
name: type-annotations-and-documentation
description: Use when defining functions to ensure clarity and maintainability.
---
1. For every public function, include type annotations for all parameters and the return value.
2. Write a clear docstring for each function that describes its purpose, parameters, and return value.
3. Ensure that the docstring follows a consistent format (e.g., Google style, NumPy style).
4. Review existing functions to add missing type annotations and docstrings.
5. Use descriptive names for parameters and return values to enhance readability.
6. If a function has multiple return paths, ensure that the docstring reflects all possible return types.
7. Regularly update documentation to reflect any changes in function behavior or parameters.

**Self-check:**
- Are all public functions annotated with types?
- Do all functions have clear and informative docstrings?
